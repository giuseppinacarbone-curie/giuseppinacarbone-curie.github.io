Mini-progetto: package scuola

Tre classi che collaborano: Studente, Corso, Registro + classe Main per avviare. Tutte nello stesso package, quindi si vedono senza import.

File 1: Studente.java

package scuola;

public class Studente {
    private String nome;
    private int voto;

    public Studente(String nome) { this.nome = nome; }

    public String getNome() { return nome; }
    public int getVoto() { return voto; }

    public void setVoto(int voto) {
        if (voto >= 0 && voto <= 10) this.voto = voto;
        else System.out.println("Voto non valido per " + nome);
    }
}

File 2: Corso.java

package scuola;
import java.util.ArrayList;

public class Corso {
    private String titolo;
    private ArrayList<Studente> iscritti = new ArrayList<>();

    public Corso(String titolo) { this.titolo = titolo; }

    public void iscrivi(Studente s) { iscritti.add(s); }

    public void stampaIscritti() {
        System.out.println("Corso: " + titolo);
        for (Studente s : iscritti)
            System.out.println("- " + s.getNome() + " voto: " + s.getVoto());
    }
}

File 3: Registro.java

package scuola;

public class Registro {
    public void promuoviTutti(Corso corso) {
        System.out.println("Registro: appello completato.");
    }
    public double media(int... voti) {
        if (voti.length == 0) return 0;
        int somma = 0;
        for (int v : voti) somma += v;
        return (double) somma / voti.length;
    }
}

File 4: Main.java (avvia tutto)

package scuola;

public class Main {
    public static void main(String[] args) {
        Studente a = new Studente("Aisha");
        a.setVoto(9);
        Studente b = new Studente("Marco");
        b.setVoto(7);

        Corso java = new Corso("Java Base");
        java.iscrivi(a);
        java.iscrivi(b);
        java.stampaIscritti();

        Registro r = new Registro();
        System.out.println("Media: " + r.media(a.getVoto(), b.getVoto()));
    }
}

Cosa osservare

  • Incapsulamento: voto è privato, passa da setVoto che controlla 0-10.
  • Collaborazione: Corso contiene Studente, Main li usa insieme.
  • Package: tutti i file hanno package scuola; in alto e stanno nella cartella scuola/.
