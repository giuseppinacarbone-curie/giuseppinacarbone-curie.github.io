A cosa servono le classi?

Le classi servono a organizzare il codice attorno a cose che esistono nel problema da risolvere: uno studente, un conto, un prodotto, un nemico di un videogioco.

1. Modellare la realtà

Raggruppi dati (attributi) e comportamenti (metodi) insieme. Es. ContoBancario ha saldo + preleva().

2. Evitare ripetizioni

Scrivi la classe una volta, crei tanti oggetti con new. Niente copia-incolla.

3. Riuso ed estensione

Con l'ereditarietà riusi codice esistente e lo specializzi.

4. Proteggere i dati

Con l'incapsulamento decidi chi può modificare cosa, evitando errori.

5. Lavorare in gruppo

Ognuno lavora su una classe diversa dello stesso package, con interfacce chiare.

6. Manutenzione facile

Se cambia una regola, la cambi in un solo punto: dentro la classe.

Senza classi vs con classi

// SENZA classi: dati sparsi
String nome1 = "Marco"; int voto1 = 8;
String nome2 = "Sara"; int voto2 = 9;

// CON classi: tutto ordinato
Studente m = new Studente("Marco");
Studente s = new Studente("Sara");
m.stampaPagella();
s.stampaPagella();
