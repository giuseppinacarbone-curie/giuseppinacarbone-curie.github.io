Classe in 30 secondi

public class Studente {
    String nome;
    int voto;

    public Studente(String nome) {
        this.nome = nome;
    }

    public void promuovi() {
        voto = 10;
        System.out.println(nome + " promosso!");
    }
}

// Uso:
Studente s = new Studente("Aisha");
s.promuovi();

La classe è lo stampo, l'oggetto è ciò che crei con quello stampo.
